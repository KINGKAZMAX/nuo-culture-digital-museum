## 1. 观展模式

首次进入展馆自动加载点云模型与手势引擎。摄像头默认关闭，可在设置面板（顶栏「设 置」）中开启；开启后浏览器会请求摄像头权限，画面仅在本机用于手势识别，不做任何上传。

左下角 HAND 小视图实时显示 21 点手部骨架与当前识别的手势名，用于手势校准与演示。

## 2. 鼠标与触屏交互

| 操作 | 效果 | 实现细节 |
|---|---|---|
| **单击**舞台空白处 | 切换到下一件展品 | 仅当位移 ≤ 6px（非拖拽）且未检测到手时触发；转场为 1 秒交叉淡切 |
| **拖拽** | 赋予藏品旋转速度（带惯性） | 水平位移 × 14、垂直位移 × 11 注入角速度（°/s），指数衰减系数 `exp(-3.2·dt)`；俯仰角限制在 ±63°（±1.1 rad） |
| **滚轮** | 缩放视野 | 每格滚轮 `zoom ×= exp(-deltaY × 0.0012)`，约 ±12%/格 |
| **触屏双指捏合** | 缩放视野 | 按两指间距比值实时缩放 |
| 无输入时 | 藏品缓慢自转 | 自转速度由面板「自动旋转 °/s」控制（−60…60） |

## 3. 手势交互

基于 MediaPipe Tasks Vision 的 GestureRecognizer：每只手 21 点骨架 + 8 类手势分类，wasm 本地推理（GPU delegate），最多同时跟踪 2 只手。旋转与捏合只认第一只手；握拳任意一只手都生效。

### 3.1 手势一览

| 手势 | 效果 | 参数 |
|---|---|---|
| **手掌移动** | 藏品跟随旋转 | 见 3.2 旋转映射 |
| **拇指食指捏合** | 切换下一件展品 | 见 3.3 捏合切换 |
| **握拳**（Closed_Fist） | 傩面爆散为星尘，松手回聚 | 见 3.4 握拳爆散 |
| **双手拉距** | 视野缩放 | 见 3.5 双手缩放 |
| 无手 | 自转展示，爆散缓慢回落 | — |

### 3.2 旋转映射（手掌移动）

手腕（landmark 0）的屏幕归一化坐标线性映射为旋转目标角，含自拍镜像：

| 轴 | 输入 | 映射区间 | 说明 |
|---|---|---|---|
| 绕 Y（左右转） | 手腕 x（镜像后） | −120° … +120° | 水平移动手掌控制朝向 |
| 绕 X（俯仰） | 手腕 y | +50° … −90° | 垂直移动手掌控制俯仰 |

- **旋转灵敏度**：面板 0–2 倍率（默认 1），放大或缩小映射幅度
- **平滑**：指数平滑，时间常数 τ ≈ 0.5 s（对应原交互设计 2 s 平滑窗口的观感），手离开后 τ 缩短为 0.6 倍以更快回到自转
- 手离开画面后，俯仰角平滑回 0，自转继续

### 3.3 捏合切换

捏合距离 = 拇指尖（4）与食指尖（8）的空间距离 ÷ 手掌尺度（腕 0 至中指根 9 的距离），为归一化比值：张开约 0.3+，捏合约 < 0.06。

| 参数 | 值 | 说明 |
|---|---|---|
| 触发阈值 | < **0.06** | 进入捏合态，立即切换 |
| 退出阈值（迟滞） | > **0.12** | 回到待命态，防止连续误触 |

切换序列为「内置 5 面具 + 用户上传模型」顺序循环，转场 1 秒交叉淡切；上传模型后序列长度自动更新。

### 3.4 握拳爆散

MediaPipe 手势分类输出 Closed_Fist 置信度（0–1）：

- 置信度 ≥ **0.5** 时判定握拳，之后置信度线性放大为爆散幅度目标 0…2
- **爆散强度**面板可调 0–3（默认 2），即幅度目标上限
- 爆散幅度经指数平滑（τ = 1 s）过渡：握拳时星尘扩散、流动噪声增强；松手后缓慢回落回聚
- 顶点着色器中，爆散方向 = 归一化径向 + 三维流动噪声，各粒子带随机种子，呈云雾状散开

### 3.5 双手缩放

同时出现两只手时，两腕距离 d（归一化）映射为缩放：

| 参数 | 值 |
|---|---|
| 距离区间 | d ∈ 0.15（合拢）… 0.6（拉开） |
| 缩放区间 | 0.45 … 2.55 |
| 平滑 | τ = 0.35 s |

与滚轮 / 双指捏合共用同一缩放状态。

### 3.6 自转

无手干预时藏品以基础速度持续自转（默认 21°/s，面板「自动旋转 °/s」可调 −60…60，负值反向），自转角与手势旋转角叠加输出。

## 4. 语音科普问答

底部麦克风按钮开启语音讲解，整体为离线方案：识别用浏览器 Web Speech API（zh-CN），讲解音频为预生成文件（`public/audio/tts/`，Piper 合成）。

状态机：`idle → listening → thinking → speaking → listening …`，手动关闭回到 idle。

1. 点击麦克风按钮，授权麦克风，进入聆听态
2. 说出问题（例如「傩戏和京剧有什么区别」「面具颜色代表什么」）
3. 关键词匹配知识库（`src/voice/kb.json`）：命中关键词数量最多者胜，平局比命中词总长度；未命中播放兜底提示
4. 播放对应讲解音频，同时展示讲解稿 8 秒

知识库 17 个主题：

`什么是傩` `傩戏与舞蹈` `面具起源` `面具颜色的含义` `贵州傩` `萍乡傩` `傩戏与京剧` `驱疫仪式` `现代传承` `数字化保护` `点云技术` `切换面具` `握拳彩蛋` `观展提示` `乐器` `流派` `兜底应答`

## 5. 背景音乐

- 曲目：归零《魔鬼花园》（2026 重录版），127 秒，循环播放，本地自托管
- 受浏览器自动播放策略限制，首次任意交互（点击 / 按键）后自动开始
- 设置面板可调音量（0–1，默认 0.45）与开关，配置持久化

## 6. 展签文案编辑

主标题、英文副题、中文副题三处展签文字可直接就地编辑：

- **双击（或单击）文字**进入编辑（`contenteditable`），输入后点击别处（失焦）即保存
- 主标题 / 中文副题按 Enter 即保存；英文副题支持 Enter 换行（竖排展示）
- 亦可在设置面板「文案」区修改，与就地编辑双向同步
- 配置存入 localStorage（键 `nuo-mask-cfg-v2`），刷新自动恢复

## 7. 设置面板

顶栏「设 置」打开，实时生效并持久化。

### 手势交互

| 项 | 范围 / 默认 | 说明 |
|---|---|---|
| 摄像头 | 设备列表 | 多摄像头时选择 |
| 启用摄像头 | 开 / 关 | 关闭后仅鼠标触屏交互 |
| 自动旋转 °/s | −60 … 60 | 无手时自转速度 |
| 旋转灵敏度 | 0 … 2 | 手腕→旋转映射倍率 |
| 平滑时间 s | 0 … 3 | 旋转跟随快慢 |
| 爆散强度 | 0 … 3 | 握拳爆散幅度上限 |

| 粒子大小 | 0.3 … 3 | 点云粒子直径倍率 |

### 文案

### 模型

## 8. 模型上传

设置面板 →「模型」→「＋ 上传模型」，支持：

- `.ply` 点云（binary / ascii；含顶点色则带色，自动按步长采样至约 40 万点内）
- `.glb` / `.gltf` / `.obj` 网格（自动表面采样转为点云，取顶点色或材质色）

上传后自动归一化尺寸与居中，立即加入捏合 / 单击切换序列，并持久化保存于浏览器 IndexedDB（刷新不丢）。列表中自定义模型带「删除」按钮，内置五面具不可删；每项均可点「查看」直接切换展示。

资产格式与缓存细节见 [性能与资产](性能与资产.md)。
