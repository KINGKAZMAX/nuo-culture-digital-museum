| 资产 | 内容 | 点数 | gzip 体积 |
|---|---|---|---|
| `nuo1–nuo5.tdp.gz` | 五面傩戏面具（内置展品） | 65,536 / 面 | 1.06–1.25 MB / 面 |
| `bg-a.tdp.gz` | 近距蓝紫星云（与面具同空间） | 65,536 | 1.26 MB |

## 2. TDPC 点云格式（内置展品）

`.tdp.gz` = **TDPC** 二进制点云 + **gzip** 整体压缩。TDPC 为全精度浮点格式，用于经过高精度同步采集的内置展品——位置与颜色已在资产侧按最终展陈状态烘焙，运行时恒等变换、零再加工。

二进制布局（小端）：

```
偏移   长度            内容
0      4               magic "TDPC"
4      4               u32 点数 n
8      n × 24          每点 24 字节：
                         f32 x, y, z     位置（世界坐标，已烘焙）
                         f32 r, g, b     颜色（sRGB 0..1）
整体再经 gzip 压缩存储为 .tdp.gz
```

颜色约定：资产内为 sRGB，加载时逐点做 γ2.2 转换至线性空间，保证渲染色彩一致。

## 3. BPC1 量化格式（用户上传）

浏览器端上传的模型转换为 **BPC1** 量化格式存储（体积优先）：

```
偏移   长度            内容
0      4               magic "BPC1"
4      4               u32 点数 n
8      12              f32 bbox.min[3]
20     12              f32 bbox.max[3]
32     n × 10          每点 10 字节：
                         i16 x, y, z     量化位置（0..65535 映射至包围盒）
                         u8  r, g, b, a  量化颜色
```

加载时反量化并做归一化：以包围盒中心为原点居中，最大边缩放至 2.6 世界单位（与内置面具同尺度）。16-bit 量化 + gzip 使体积约为全精度格式的 1/6。

> 加载器 `src/pointCloud.js` 同时识别 `TDPC` 与 `BPC1` 两种 magic，按魔数自动分发。

## 4. manifest.json 字段

`public/models/manifest.json` 是展陈元数据的唯一入口（以下为当前实际值）：

| 字段 | 值 | 说明 |
|---|---|---|
| `format` | `"tdp"` | 资产格式标识 |
| `models.<name>.count` | `65536` | 每面面具点数 |
| `models.<name>.bytes` | 如 `1198304` | gzip 后字节数（预读体积估算） |
| `camera.fov` | `45` | 相机垂直视场角（°） |
| `camera.z` | `5` | 相机位置（0, 0, 5）正对原点 |
| `sprite.radius` | `0.005` | 点精灵半径（世界单位，直径 0.01） |
| `lights[].pos` / `dimmer` | 双点光源坐标与强度（0.995 / 2.0） | 着色器内以双光源漫反射实现 |
| `background.bg-a` | `count / transform1.scale / bounds / colorMean / bytes` | 近距星云（蓝紫，均值色 ≈ 0.34, 0.32, 0.55） |
| `background.bg-b` | 同上 | 远景环境云（金橙，均值色 ≈ 0.82, 0.60, 0.24），`constant2.color: null` 表示保留原色 |

`background` 段由资产管线生成；缺失时加载器静默跳过并退回程序化星空。

## 5. 加载与缓存策略

启动序列（`src/main.js`）：

1. **manifest 预读**：`fetch('./models/manifest.json')`，带重试（退避 400ms × 重试次数）
2. **首个展品阻塞加载**：解析 → 注册表构建 → 首件展品就绪后才揭开展厅
3. **下一件预载**：首件就绪后立即后台预载序列中的下一件，切换近零等待
4. **背景非阻塞加载**：背景星云加载失败不影响主展陈

单文件解码流程（`src/pointCloud.js`）：

```
fetch .tdp.gz → 检查 gzip 魔数 (1F 8B，兼容透明解压的宿主)
  → DecompressionStream('gzip') 流式解压
  → DataView 按 TDPC/BPC1 布局解析
  → 直建 Float32Array(position/color) + BufferGeometry
```

- 解压使用浏览器原生 `DecompressionStream`，零第三方依赖
- **几何缓存**：`Map` 上限 8 件，超出按先进先出淘汰（保护当前展品与最新加载项）；被淘汰展品再次切换时重新解码
- **光晕层**：每件展品由 1 个主层 + 若干层反馈光晕层（着色器 `uGhost` 1..4，透明度递减）构成，历史帧漂移噪声形成拖影光晕

## 6. 渲染与性能预算

| 项 | 预算 / 配置 |
|---|---|
| 总点数 | 面具 327,680 + 背景 73,636 ≈ **40 万点** |
| 相机 | PerspectiveCamera fov 45，位置 (0, 0, 5) |
| 点尺寸 | 世界直径 0.01 × 倍率（面板 0.3–3），屏幕投影像素 clamp 1–20 px |
| 后期 | UnrealBloom（strength 0.7 / radius 0.55 / threshold 0.42） |
| 着色器 | 单 pass 顶点噪声爆散 + 片元球体伪法线双光源漫反射，NormalBlending、depthWrite 关闭 |
| 手势推理 | MediaPipe wasm，GPU delegate，逐视频帧（`recognizeForVideo`），不占用主渲染循环 |
| 帧率目标 | 桌面 Chrome / Edge 60 fps；移动端建议调低「粒子大小」 |

降级路径：无摄像头 → 单击切换 + 拖拽旋转；无 Web Speech API → 语音问答不可用（其余功能不受影响）；IndexedDB 不可用 → 用户模型仅本次会话有效。

## 7. 用户模型持久化（IndexedDB）

| 项 | 值 |
|---|---|
| 库名 / 存储 | `nuo-mask-web` / object store `models` |
| 记录结构 | `{ key, name, blob, count }`，key 形如 `u_<时间戳36>_<随机4>` |
| 写入时机 | 上传转换完成后立即 `put` |
| 读取时机 | 启动时 `getAll` 重建注册表，追加至内置五面具之后 |
| 尺度 | 统一 `baseScale: 2.6`、`baseTilt: 0`（与内置面具同尺度） |

UI 配置（文案、字体、音量、交互参数等）存 localStorage，键 `nuo-mask-cfg-v2`。

## 9. 资产管线

Node 端管线位于 `tools/`：

```bash
npm run convert                    # 批量转换点云并生成 manifest.json
npm run convert -- --stride 2      # 每 2 点取 1，体积减半
```

- `tools/convert-ply.mjs`：PLY 点云 → 量化格式 + `manifest.json`；源目录为脚本顶部 `SRC` 常量，换源需修改
- `tools/export-bg.mjs`：背景粒子云导出为 `bg-a / bg-b` 资产
