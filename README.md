## 数字非遗艺术的意义

傩，是上古驱疫纳吉的仪式，被誉为「中国戏剧的活化石」；傩面具雕刻与傩戏表演，是贵州最具代表性的非物质文化遗产之一。然而与其他许多非遗一样，傩文化面临着传承人老龄化、展演场景萎缩、年轻受众隔膜的现实困境——它活在深山的戏台上，却难以走进当代人的视野。

**数字非遗，不是把文物拍照上传，而是让文化遗产获得当代的生命形态。** 本项目正是这一理念的实践：

- **让非遗「可及」**：传统傩戏展演需要戏台、锣鼓与特定节庆场景；数字博物馆让任何人打开一个网页即可观展，突破地域与场景的限制，将黔地文化带向全国与世界。
- **让非遗「可玩」**：观展不是隔着玻璃的凝视。手势交互让观展者亲手「驱动」傩面——旋转端详雕工、捏合切换五面、握拳看星尘爆散——在游戏化的参与中建立情感联结，这正是 Z 世代亲近传统文化的方式。
- **让非遗「可存」**：实体傩面具会随岁月剥蚀，老艺人的记忆会随时间消逝。64 万点/面的三维点云以数字形式凝固了面具的每一道刀痕与敷彩，为非遗建立可永久保存、可精确度量的数字档案。
- **让非遗「可传」**：项目全部开源，支持上传自有模型扩展馆藏。博物馆不是终点，而是可持续生长的文化平台——学校可用于美育课件，文旅可用于数字展厅，研究者可用于形态比对。

技术的价值，在于让被时间尘封的美重新参与当代生活。当古老的傩面在浏览器中随观展者的手掌流转，人神共戏的千年仪式便完成了一次数字时代的转身。

## 展馆亮点

- **五面真迹级点云傩面**：真实傩戏面具模型经自研量化管线压缩为 `.bpc.gz`（单面 64 万点仅 ~5.6MB，16-bit 量化 + gzip），浏览器流畅展陈
- **裸手交互**：MediaPipe GestureRecognizer 实时识别——手掌移动旋转面具、**捏合**切换藏品、**握拳**令傩面爆散为星尘
- **GLSL 粒子着色器**：3D 流动噪声爆散、星尘闪烁、加色混合，呈现 bloom/feedback 星尘观感
- **零后端、全离线资源**：wasm、手势模型、中文字体全部自托管，断网可用、隐私零上传（手势画面不出本机）
- **可玩可改**：展签文案实时编辑（双击画面文字）、十余项展陈参数面板、支持上传 `.ply/.glb/.obj` 即时转为点云入馆（IndexedDB 持久化）

## 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 构建 | **Vite 5** | 开发/构建/预览，`base: './'` 支持任意子路径静态部署 |
| 渲染 | **Three.js 0.170** | 场景、相机、点云渲染、1s 交叉淡切转场 |
| 着色 | **原生 GLSL ShaderMaterial** | 自定义顶点/片元着色器：噪声爆散、闪烁、点尺寸衰减 |
| 识别 | **MediaPipe Tasks Vision 0.10（GestureRecognizer）** | 手部 21 点骨架 + 8 类手势，wasm 本地推理（GPU delegate） |
| 数据 | **自研 .bpc.gz 点云格式** | PLY → 16-bit 量化 + gzip，`DecompressionStream` 浏览器端解压 |
| 存储 | **IndexedDB** | 用户新增展品持久化；localStorage 存 UI 配置 |
| 字体 | **@fontsource（马善政楷/站酷小薇/思源宋）** | unicode-range 中文子集本地化 |
| 交互 | **原生手势交互设计** | 手腕位置→旋转、捏合→切换、握拳→爆散，指数平滑滤波 |

### 技术选型理由

- **Three.js 而非模型查看器**：64 万点 + 自定义粒子行为必须手写着色器，Viewer 类库封装过深。
- **MediaPipe GestureRecognizer 而非 Pose/Face**：手势 one-hot 与捏合距离直接映射交互状态机；且 wasm 纯前端推理，展会现场弱网可用。
- **量化点云格式而非 glTF**：点云只需 position+color，16-bit 量化将内存与体积压至 1/6，gzip 后再折半，浏览器解压零依赖。
- **Vite 而非框架全家桶**：单页装置型应用无路由/状态树需求，原生 ES Module 最小化交付。

```bash
npm install
npm run dev      # http://localhost:5188
npm run build    # 产物 dist/，任意静态托管可部署
npm run preview  # 本地验证构建产物
```

## 模型管线

```bash
# PLY(含顶点色) -> 量化 .bpc.gz（生成 public/models/nuoN.bpc.gz）
npm run convert            # 读取 tools/ 输入目录批量转换
```

管线细节：`tools/convert-ply.mjs` 解析二进制 PLY → 包围盒归一化 → int16 量化位置 + uint8 量化颜色 → `BPC1` 头（magic/count/min/max）→ gzip。前端 `src/pointCloud.js` 流式解压并直建 `BufferGeometry`。

## 关于傩

傩是上古驱疫纳吉之仪式，傩戏被誉为「中国戏剧活化石」。黔地德江傩堂戏、安顺地戏、威宁撮泰吉均为国家级非遗。傩面「以色喻德」：红表忠勇、黑表刚直、金表神异。本馆以数字点云为刻刀，让更多人隔屏照面千年傩韵。
